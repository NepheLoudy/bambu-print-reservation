# qianli 运维台（仅本机运行）

可视化查看 qianli 项目群全部机器人的**端口职能、权限边界、指令清单、对话监听、服务状态、
运行日志、更新状态**，并提供**本地测试进程启停**、**npm push / 安装 / stub 测试**快捷指令，
以及**定制中心**——直接在界面上读写各机器人后端的定制项（白名单/名册/管辖策略/关键词回答表）。

> 仅绑定 127.0.0.1，不部署 NAS、不对外暴露。

## 启动

```bash
cd dashboard
npm install
npm start        # http://127.0.0.1:3100
```

## 能看什么

| 区块 | 内容 |
| --- | --- |
| 服务状态 | NAS pm2 全进程（状态/重启次数/运行时长/内存，SSH `pm2 jlist`）+ 本地测试进程与健康检查 |
| 职能与权限 | 每个项目的角色、监听链路、指令/接口、权限边界（`registry.js` 为单一事实来源） |
| 更新状态 | 各仓 git 分支 / 最新提交 / 未提交改动数 |
| 运行日志 | NAS pm2 日志（SSH tail ~/.pm2/logs）+ 本地测试进程实时输出 |
| **定制中心** | 各机器人后端定制窗口（`registry.js` 的 `windows` 清单）：白名单增删、名册全景与通讯录刷新、管辖策略/定制项全景、关键词回答表可视化编辑（增删改/启停/切表），读写经 `/api/nas/api`（SSH curl）直达 NAS 本机接口 |

## 能做什么

- **本地测试启动/停止**：一键在本机跑起任意机器人（自动 `QUIET_HOURS_DISABLED=1`，
  手动测试不受晚间静默限制）；本地实例可直接调它的 `/api/bot/test-*` 等接口做干跑。
- **快捷指令**：npm install、各项目 stub 测试、**npm run push 部署**（带提交说明输入与二次确认，
  push = 提交 → GitHub → NAS → pm2 重启，qianli-deploy 链路）。
- **NAS 重启**：单进程 pm2 restart + save（带确认）。
- **定制中心**：白名单加人/移人（即时生效）、触发名册通讯录同步、查看各域 policy 全景、
  编辑 hub 关键词回答表（改动写 NAS `.local.json` 即时生效；npm push 会用本地 xlsx 版覆盖，
  持久批量编辑仍以本地 `关键词回答表.xlsx` 为准）。

## 安全与隐私

- 只读凭据：NAS 连接信息**直读 `../approval-bot/.env`**（不复制、不入库）；
- `registry.js` 只写职能与配置键名，不写真实姓名/群号/凭据；
- 本地测试进程日志只存在内存环形缓冲（600 行），不落盘、不上传。
